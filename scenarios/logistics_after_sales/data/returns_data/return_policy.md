# 退件、改址与退款边界（合成演示政策）

本文是开发用的虚构政策，不代表真实承运商或商家的业务流程。

## 修改退件地址

先核对退件状态，再确认新地址得到授权。进入不可修改阶段时提交人工工单，由处理人员判断是否可以协调。知识助手只解释规则，不修改地址或执行拦截；不得把已解释的规则描述成已经执行成功。

## 拒收与交易退款

物流退回与交易退款是不同流程。先核对退回签收凭证，由商家按订单规则审核退款。没有商家审核结果和支付渠道状态时，不承诺退款到账时间。

## 审核记录

记录请求类型、授权依据、处理状态与最终确认人。客户的完整地址只保存在有访问权限的业务系统中；本仓库只收录合成知识资料。
